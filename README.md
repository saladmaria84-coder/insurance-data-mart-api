# 📊 Автоматизация витрины данных страховой компании с интеграцией API

Этот проект предназначен для объединения данных по клиентам, договорам и страховым выплат с автоматическим пересчетом рублевых сумм в валюту USD по актуальному курсу ЦБ РФ.

---

## 🛠 Использованные технологии и библиотеки
* **Python 3.x**
* **Pandas** — очистка, объединение (`merge`) и формирование витрины данных
* **Requests** — взаимодействие с JSON API ЦБ РФ для получения курсов валют
* **OpenPyXL** — чтение и запись файлов Excel

---

## 📋 Описание этапов работы
1. **Сбор данных:** Загрузка и первичный анализ исходных датасетов (`CASE_CONTRACTS`, `CASE_LOSSES`, `experiment_group`).
2. **Интеграция с API:** Автоматический запрос к API Центробанка РФ для получения текущего курса US Dollar.
3. **Обработка данных:**
   * Объединение таблиц по уникальному ключу `client_id`.
   * Конвертация страховых сумм и выплат из RUB в USD.
4. **Экспорт:** Сохранение итоговой витрины данных в формат `.xlsx` (`insurance_datamart_final.xlsx`).

---
